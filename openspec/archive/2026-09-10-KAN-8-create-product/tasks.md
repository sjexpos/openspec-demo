# KAN-8 Create Product (`POST /api/products`) — Implementation Tasks

Backend-only change. Sources of truth: `proposal.md` (why / scope), `specs/products-management/spec.md`
(8 requirements, 18 scenarios), `design.md` (decisions D1–D15, file layout, guard order, testing plan).

**Working rules that apply to every task below**

- **Strict TDD, baby steps (project core principle §1 + `test-driven-development` skill).** Every
  implementation task is preceded by its own failing-test task. Run the test, watch it fail for the
  right reason (missing type, wrong status, wrong value — not a typo), then write the *minimal* code to
  make it pass. Never write test and production code in the same task. Never write production code
  before its test.
- **One task at a time**, in the order listed; the order is the dependency order.
- All new files carry the GNU GPL header + `// Copyright (c) 2026-2027 Sergio Exposito.` line.
- English only, in code, comments, test names, commit messages and reports.
- Test naming: `should_[expected_behavior]_when_[condition]`, Arrange/Act/Assert.
- Coverage gate: 90% for branches, functions, lines and statements (`mvn test`).
- **Test infrastructure fact (verified, do not re-derive):** there is **no Testcontainers**.
  `src/test/resources/application.yml` points `@DataJpaTest` and `@SpringBootTest` at a **real local
  PostgreSQL** `jdbc:postgresql://localhost:5432/tests` with Flyway enabled. The `postgres` service in
  `docker-compose.yml` must be running before any integration test and before manual curl testing.
- **Reference-data fact (verified):** a fresh database seeds only `license_statuses`. `collections`,
  `categories`, `subcategories`, `units`, `strain_types`, `seed_companies`, `strains` and `brand_types`
  are all empty, so every `POST /api/products` returns 404 until fixtures are seeded. `strain_types` and
  `seed_companies` must be seeded with **native SQL** because D5 deliberately does not map them, while
  `strains.strain_type_id` / `seed_company_id` are `NOT NULL`.
- `docs/data-model.md` is **corrected**, not merely reviewed (D13).
